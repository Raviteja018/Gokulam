# GOKULAM — Traditional Courtyard Restaurant

An agency-grade, responsive website for **CAFE GOKULAM** (located at *240, Kukatpally Housing Board Colony, K P H B Phase 6, Kukatpally, Hyderabad, Telangana 500085*).

Built with **React**, **Tailwind CSS**, and **Vite**, translating Gokulam's physical courtyard atmosphere—red Mangalore tiled gables, illuminated 3D night signage, warm decorative lanterns, cane mudda stools, wooden lattice fencing, and clay-oven & wok culinary craft—into a digital experience.

---

## 🌟 Key Features

- **Traditional Krishna-Inspired Brand Identity**:
  - Custom display serif wordmark with a commanding, taller initial **“G”**.
  - Handcrafted Indian bamboo flute (*bansuri*) starting beneath the letter **“U”**, with cylindrical bamboo gradient shading, terracotta thread bindings (*dhaga*), embouchure, melodic tone holes, and hanging peacock feather tassel.
- **Dynamic Courtyard Ambiance Mode**:
  - Interactive toggle switching between **Daylight Courtyard** and **Twilight Lantern Glow** atmosphere across the entire UI.
- **Dedicated Editorial Menu Book (`/menu`)**:
  - Comprehensive catalog of 70+ authentic dishes with exact restaurant pricing.
  - Organized category switcher: Biryani & Specials, Chicken Starters, Prawns & Fish, Egg Starters, Fried Rice, Wok Noodles.
  - Real-time dietary filter (Veg, Non-Veg, Egg, Seafood) and search.
  - Dish photo preview modal and scanned physical menu sheets lightbox.
- **Agency-Grade Mobile Experience**:
  - 100% solid, full-screen mobile navigation modal with zero background bleed-through.
  - Editorial numbered menu items (`01` to `05`) and automatic body scroll locking.
- **Integrated Google Business Listing**:
  - Official Google Maps iframe embed for **CAFE GOKULAM**.
  - Google rating showcase (**4.1 ★**, 96+ reviews).
  - One-click navigation to Google Maps.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Routing**: React Router DOM v6
- **Styling**: Tailwind CSS, Vanilla CSS
- **Icons**: Lucide React
- **Bundler**: Vite
- **Fonts**: Cinzel (Display Serif), Playfair Display, Plus Jakarta Sans

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Raviteja018/Gokulam.git

# Navigate into the project folder
cd Gokulam

# Install dependencies
npm install

# Start development server
npm run dev
```

The development server will run at `http://127.0.0.1:5174/` or `http://localhost:5173/`.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
